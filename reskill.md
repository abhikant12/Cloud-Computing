## ✅ **What Can Happen After a Cyber-Attack?**

* **Financial Loss** – Theft of money or data can result in heavy financial damages.
* **Reputation Damage** – Loss of trust from customers, clients, and the public.
* **Loss of Personal Data** – Leakage of sensitive personal or customer information.
* **Disruption** – Service interruptions, downtime, or failure of critical systems.
* **Loss in Business** – Revenue decline due to operational shutdowns or legal issues.

---

## 🛡️ **What is Cyber Security?**

Cyber Security is the **protection of internet-connected systems**—including hardware, software, and data—from **cyber threats**, using various **security controls**.

---

## 💣 **Types of Cyber Threats (Explained in Short):**

| Threat                                   | Explanation                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------- |
| **Virus**                                | A program that attaches itself to files and spreads when the file is executed.  |
| **Worm**                                 | A standalone malware that replicates itself and spreads without user action.    |
| **Trojan Horse**                         | Disguised as a legitimate program but performs malicious actions.               |
| **Ransomware**                           | Locks or encrypts data and demands payment (ransom) to restore access.          |
| **Spyware**                              | Secretly collects user data like keystrokes, passwords, and activities.         |
| **Phishing**                             | Fake emails/websites trick users into revealing personal info or credentials.   |
| **DDoS (Distributed Denial of Service)** | Overwhelms a server/network with traffic to cause disruption.                   |
| **Botnet**                               | A group of infected devices controlled remotely to perform large-scale attacks. |
| **Backdoor**                             | A hidden access point into a system, bypassing normal security.                 |
| **AI & IoT-based Attacks**               | Exploits vulnerabilities in smart devices and AI systems for malicious use.     |

---

## 🎯 **Security Objectives: CIA Triad**

| Component           | Purpose                                                       |
| ------------------- | ------------------------------------------------------------- |
| **Confidentiality** | Ensure that data is accessed only by authorized people.       |
| **Integrity**       | Protect data from unauthorized changes or corruption.         |
| **Availability**    | Ensure timely and reliable access to information and systems. |

---

## 🔐 **What Supports Security Objectives? (AAA Model)**

| Term                             | Meaning                                                           |
| -------------------------------- | ----------------------------------------------------------------- |
| **Authentication**               | Verifies the identity of the user (e.g., username/password).      |
| **Authorization**                | Determines what actions a user is allowed to perform.             |

## ✅ **Artificial Intelligence (AI)**

* **Definition**: Simulation of human intelligence by machines.
* **Includes**: Learning, reasoning, problem-solving.
* **Branch**: Machine Learning (ML) is a subset of AI.

---

## 🤖 **Machine Learning (ML)**

* **Definition**: Uses data and algorithms to help machines learn patterns and improve over time.
* **Types**:

  * **Supervised Learning**: Uses labeled data (input + known output).
  * **Unsupervised Learning**: Uses unlabeled data to find hidden patterns.

---

## 🌐 **Generative AI (GenAI)**

* **Definition**: AI that generates new content (text, image, code, etc.) from learned data.
* **Training Process**: Involves creating a stochastic model from large datasets.
* **Output**: Generated by predicting the next probable content from a prompt.

---

## 🔁 **Types of GenAI Models (based on input/output)**

| Model Type    | Input | Output    | Examples/Tools                       |
| ------------- | ----- | --------- | ------------------------------------ |
| Text-to-Text  | Text  | Text      | ChatGPT (essays, answers, summaries) |
| Text-to-Image | Text  | Image     | DALL·E 2, Stable Diffusion           |
| Text-to-Video | Text  | Video     | Synthesia, Elai.io                   |
| Text-to-3D    | Text  | 3D Object | 3D modeling for games                |
| Text-to-Task  | Text  | Action    | Calendar updates, emails, etc.       |

---

## 🔍 **Types of AI Models**

1. **Discriminative Models**

   * Learn to distinguish between classes (e.g., A vs B).
   * Predict labels or values (classification/regression).

2. **Generative Models**

   * Learn data patterns to generate new content.
   * Examples: Text generation, image synthesis, summarization, code generation.

---

## ⚙️ **GenAI Architectures**

* **Transformer Architecture** (for text)

  * Solves sequence tasks.
  * Handles long-range dependencies (context-aware).
* **Latent Diffusion Model** (for images)

  * Uses an autoencoder: Compresses (encoder) and reconstructs (decoder) images.
  * Samples from latent space to generate realistic images from prompts.

---

## ✏️ **Prompt & Prompt Design**

* **Prompt**: Text input to guide the GenAI model.

  * Example:

    * *Write an HTML table with 3 rows and 3 columns*
    * *Image of a dinosaur taller than trees with a clear sky*
* **Prompt Design**: Crafting prompts effectively to get desired results.

---

## 📌 **Other Important Terms**

* **Foundational Model**: A large GenAI model trained on broad data, fine-tuned for specific tasks (e.g., Q\&A, summarization).
* **Training**: The learning phase of the model using large datasets.
* **Inference**: The generation or output phase based on a given prompt.

### **📌 Short Notes on Large Language Models (LLMs), Generative AI, and Related Concepts**

#### ✅ **Large Language Models (LLMs):**

* Advanced NLP models trained on large datasets (books, articles, websites).
* Handle tasks like text generation, translation, summarization, sentiment analysis.
* Examples: **GPT-3**, **BERT**.
* Use **transformer architecture** with **self-attention** for contextual understanding.
* LLMs are **pre-trained** and then **fine-tuned** for specific tasks.

#### ✅ **Transformer Architecture:**

* Backbone of LLMs.
* Uses **self-attention** to understand relationships between words.
* Enables better handling of long-range dependencies in text.

#### ✅ **Training of LLMs:**

* **Pre-training**: On vast, unlabeled text for general language patterns.
* **Fine-tuning**: On smaller, task-specific datasets (e.g., summarization, Q\&A).

#### ✅ **Components of Language Models:**

* **Encoder**: Converts input text to embeddings.
* **Decoder**: Converts embeddings back to text.
* **Fill-in-the-Blank Models**: Predict missing words using the entire model pipeline.

#### ✅ **Foundation Models:**

* Large-scale models trained on general data.
* Serve as the **base for many NLP tasks**.
* Can be adapted (via fine-tuning) for specific domains.

#### ✅ **Generative AI:**

* Uses LLMs to generate content (text, code, images, etc.).
* Applied in:

  * **Software Development**: Code gen, testing, documentation.
  * **Business**: Banking, Insurance, Healthcare, Manufacturing.

#### ✅ **Open-Source vs Closed-Source Models:**

| Feature       | Open Source        | Closed Source |
| ------------- | ------------------ | ------------- |
| Transparency  | High               | Limited       |
| Cost          | Often Free         | Paid          |
| Examples      | HuggingFace, LLaMA | ChatGPT, Bard |
| Customization | Easy               | Restricted    |

#### ✅ **Limitations of ChatGPT (OpenAI):**

1. Can generate **plausible but wrong** answers.
2. No fixed source of truth in **RL (Reinforcement Learning)** training.
3. Being overly cautious may prevent correct answers.
4. Supervised training might not align with model knowledge.

#### ✅ **Responsible Use of LLMs:**

* Use for **productivity enhancement**.
* Treat as **Subject Matter Experts (SMEs)** with human oversight.
* Re-imagine workflows using AI tools.

LLM stands for Large Language Model. It’s a type of deep learning model trained on massive amounts of text data to understand, generate, and manipulate human language. LLMs use transformer architecture with self-attention mechanisms, which allows them to capture context and meaning across long text sequences. Examples include models like GPT (Generative Pre-trained Transformer) and BERT. LLMs are used in applications like chatbots, content generation, translation, and sentiment analysis.
